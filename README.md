# Clone Website

A responsive frontend practice project built with **HTML and CSS**.

## ✨ Highlights

- Responsive website layout
- Custom CSS styling
- Image-based UI sections
- Separate HTML, CSS and image assets

## 📁 Structure

- `index.html` — main page
- `css/` — stylesheets
- `image/` — project assets

## ▶️ Run locally

Open `index.html` in a browser or use the VS Code Live Server extension.

## 🎯 Purpose

This project is part of my frontend development practice, focused on converting visual designs into responsive web interfaces.
